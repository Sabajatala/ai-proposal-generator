# AI Proposal Generator

Full-stack application using:

- React (Vite)
- Node.js / Express
- MongoDB
- Docker

## Run Locally with Docker

Clone the repository:

git clone < https://github.com/Sabajatala/ai-proposal-generator >

Navigate to project:

cd ai-proposal-generator

Build and run containers:

docker compose up --build

Frontend will run on:

http://localhost:5173

Backend API will run on:

http://localhost:5000
